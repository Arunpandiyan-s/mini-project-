# StayEase Staff Hub

# Lovable AI Prompt – StayEase Staff Portal

Create a **premium responsive hotel staff web application** called **StayEase Staff Portal** for a Smart Hotel Operations Platform. The application must work perfectly on **mobile phones, tablets, laptops, and desktop computers**. Use a modern hospitality design with white background, soft blue accents, subtle gold highlights, rounded cards, large touch-friendly buttons, clean typography, and minimal typing.

The portal is for hotel staff and managers only. The goal is to help staff perform daily tasks quickly and help managers monitor the entire hotel in real time.

---

Create a full-screen welcome page with the title **“StayEase Staff Portal”** and subtitle **“Select your department to continue.”**

Display six large role cards with icons:

* Receptionist

* Maintenance

* Manager

Each card should be clickable and lead to the login page while remembering the selected role.

Features:
